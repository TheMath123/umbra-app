# Idiomas (i18n)

O MD Reader vem em Português (Brasil) e English. Qualquer pessoa pode contribuir com um novo idioma — não precisa saber programar, só editar um arquivo `.json`.

## Como funciona

Cada idioma é um arquivo em `src/lib/locales/<código>.json`: um objeto simples de `"chave": "texto"`, sem aninhamento. Por exemplo, um trecho de `pt-BR.json`:

```json
{
  "settings.title": "Configurações",
  "settings.fontLabel": "Fonte do texto",
  "export.exportButton": "Exportar"
}
```

A **chave** (`settings.title`) nunca muda entre idiomas — é só um identificador interno, o prefixo antes do ponto indica de qual parte do app aquele texto vem (`app`, `menu`, `prompt`, `settings`, `shortcuts`, `themes`, `export`, `help`, `zoom`, `tabs`, `editor`). O **valor** é o texto que aparece na tela, e é isso que muda de um arquivo de idioma para o outro.

## Criando um novo idioma

1. Copie `src/lib/locales/en.json` (a referência mais completa) para um novo arquivo, nomeado com o [código de idioma](https://pt.wikipedia.org/wiki/ISO_639-1) apropriado — `es.json` para espanhol, `fr.json` para francês, `pt-PT.json` para português europeu, etc.
2. Traduza só os **valores** (o texto depois dos dois-pontos). Nunca traduza as chaves.
3. Placeholders como `{count}`, `{name}`, `{version}` são substituídos em tempo real por um valor (número, nome de arquivo, versão) — mantenha-os exatamente como estão, só mude a posição deles na frase se a gramática do idioma pedir. Por exemplo:
   ```json
   "app.currentLine": "Line {current} of {total}"
   ```
   pode virar, em outro idioma, `"Ligne {current} sur {total}"` — os `{current}`/`{total}` continuam lá, só a frase ao redor muda.
4. Uma chave que faltar no seu arquivo simplesmente aparece em Português (o idioma de referência) até alguém traduzir — não precisa traduzir tudo de uma vez para o idioma já funcionar parcialmente.
5. Para o idioma aparecer no seletor (Configurações → Idioma), registre-o em `src/lib/i18n.svelte.ts`:
   ```ts
   import es from './locales/es.json';
   // ...
   export const LOCALES: Record<LocaleId, LocaleDef> = {
     'pt-BR': { id: 'pt-BR', name: 'Português (Brasil)', strings: ptBR },
     en: { id: 'en', name: 'English', strings: en },
     es: { id: 'es', name: 'Español', strings: es } // novo
   };
   ```
   O campo `name` é como o idioma aparece no seletor — escreva-o no próprio idioma (ex.: `"Español"`, não `"Spanish"`).

## O que fica de fora, por enquanto

- **Nomes de temas embutidos** (Nord, Dracula, Sépia, Bearded — Black & Amethyst, etc.) não são traduzidos — são nomes próprios de esquemas de cores conhecidos, não texto de interface.
- **Mensagens de erro vindas do sistema de arquivos** (ex.: "Falha ao criar pasta: ...", geradas pelo backend em Rust) continuam em português — traduzir essa camada é um passo futuro, separado deste sistema.
- **Notação de atalhos de teclado** ("Ctrl+B", "Ctrl+Shift+Tab") não é traduzida — é a mesma em qualquer idioma de teclado ocidental.

## Idioma padrão

Na primeira abertura, o MD Reader detecta o idioma do sistema operacional (Português → `pt-BR`; qualquer outro → `en`) e lembra a escolha feita em Configurações a partir daí.
